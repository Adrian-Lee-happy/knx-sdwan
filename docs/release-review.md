## 发布门禁

在首次提交前必须全部满足：

1. 本地内容审计、文件 allowlist 和 gitleaks 均通过。
2. Git 暂存树与已审阅工作树一致，完整 cached diff 无异常，没有设备日志、备份、身份材料或真实地址。
3. GitHub CLI 已认证为指定账号。
4. 目标仓库不存在，或明确核验已有仓库并获得适当处理条件；禁止覆盖已有历史。
5. 创建后实际 API 返回 private=true 且 visibility=private，再次核实后才允许首次提交与推送。
6. 推送后比较远端文件树、最新提交和隐私状态。

远端发布是否完成，以本次任务最后给出的真实仓库状态和提交为准，不把本地文档当成已成功推送证据。此文档不存储认证状态、Token、设备授权码或会话日志。
